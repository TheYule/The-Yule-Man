# The Yule Man Bot

A Discord bot written in Rust with [Poise](https://github.com/serenity-rs/poise) and [Songbird](https://github.com/serenity-rs/songbird). [rig-llama-cpp](https://github.com/camperking/rig-llama-cpp) is used for loading local AI models.

## How to Run
- Make sure you have `libopus` installed
- Make sure you have `ffmpeg` installed
- Make sure you have `yt-dlp` installed
